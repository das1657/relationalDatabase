Java Swing app that sends SQL commands to update, add, remove, search, and read a Microsoft Access database, with different users which have different permission levels, using UCanAccess.

# How to run
Run relational.java inside the project folder

# Logins
You can view the default logins, add, edit, and remove users under lib/users.accdb

The default passwords are 123, 456, and 789.
